# The hold list: a green agent PR that changes a file matching one of these globs waits for
# Håkan instead of merging on its own (guard.jq `hold_globs`, `merge_verdict`). One glob per
# line, `<glob>  # <reason>`. `**` matches any path, `*` any run without `/`, `?` one character.
# The watch reads the installed copy, which matches main, so a PR can't drop a glob for itself.
# A reason that starts with `kernel:` marks the guard itself: what decides a merge, what a session
# may run, and the credentials. Main's ruleset `required_reviewers` names exactly the kernel globs
# (guard.jq `ruleset_drift`). The rest of the queue's scripts, skills and agents merge on their own.
